# UI-автотесты Ростелеком ID

Учебный проект автоматизации пользовательских сценариев единой системы авторизации Ростелеком ID.

## Что проверяется

- авторизация по телефону, электронной почте, логину и лицевому счёту;
- негативные сценарии авторизации;
- регистрация нового пользователя и валидация полей;
- восстановление доступа;
- cookie-уведомление и матрица продуктов.

## Стек и подход

- Python, Pytest;
- Selenium WebDriver и WebDriver Manager;
- Page Object Model;
- параметризация и позитивные/негативные сценарии;
- запуск Chrome в обычном или headless-режиме.

## Установка

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Тестовые данные

Логины и пароли не хранятся в репозитории. Перед запуском задайте переменные из `.env.example` в окружении. Не публикуйте заполненный `.env`.

Минимально для сценариев авторизации нужны `RT_VALID_PHONE` и `RT_VALID_PASSWORD`. Для полного набора потребуются остальные контакты и уникальный адрес для регистрации.

## Запуск

```bash
pytest tests/
pytest tests/ --headless
pytest tests/test_authorization.py --headless
```

Базовый URL можно переопределить:

```bash
pytest tests/ --base-url https://b2c.passport.rt.ru/
```

## Структура

- `pages/` — Page Object-классы и локаторы;
- `tests/` — тестовые сценарии;
- `utils/test_data.py` — чтение тестовых данных из окружения;
- `conftest.py` — настройка браузера и параметров Pytest.

## Ограничения

Проект учебный и зависит от доступности внешнего тестируемого сервиса. Сценарии отправки кода требуют отдельной тестовой учётной записи и могут быть недоступны при изменении интерфейса или правил сервиса.
